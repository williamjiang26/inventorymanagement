# Pantry Tracker

## Goal

**Pantry Tracker** is a web application designed to help restaurants track groceries in their pantry. Simply take a photo to identify grocery items.

Demo coming soon

## Tech Stack

- **Frontend:**
  - React
  - Next.js
  - ShadCN
  - TypeScript
  - Camera.js
  - HTML/CSS

- **Backend:**
  - GraphQL
  - Python
  - FastAPI
  - OpenAI API
  - DynamoDB

- **CI/CD and Auth:**
  - AWS (Lambda, Cognito, Amplify)
  - GitHub Actions
